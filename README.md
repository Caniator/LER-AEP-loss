# Aerones — Leading Edge Erosion landing page

Static landing page for the "Cost of an Eroded Edge" campaign.

- Page: `leading-edge-erosion/index.html` (served at `/leading-edge-erosion`)
- Assets: `leading-edge-erosion/assets/`
- `vercel.json`: redirects `/` to `/leading-edge-erosion`, long-cache headers for assets

## Deploy
Import this repo in Vercel (Framework preset: **Other**, no build command, output directory: root). Every push to `main` redeploys.

## Live dependencies
- Pipedrive Web Form (lead capture)
- YouTube embed (privacy-enhanced mode)
- Google Fonts (Inter)
